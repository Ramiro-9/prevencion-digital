Acordeones

Usan details y summary: funcionan con teclado y sin JavaScript.

¿Cómo se usa este componente?

Cada acordeón tiene un título visible y un contenido breve. Se abre con Enter o con un toque.

¿Qué pasa con el foco?

El resumen se puede enfocar con Tab y tiene un anillo de foco visible. El contenido no se oculta a lectores de pantalla cuando está abierto.

¿Se puede usar sin mouse?

Sí. El elemento nativo se abre y se cierra con el teclado, sin depender de JavaScript.

Línea de tiempo

Ejemplo de estructura para hitos ordenados cronológicamente.

  1. Etapa 1

    Primer hito

    Texto breve para explicar qué ocurrió y por qué importa.

  2. Etapa 2

    Segundo hito

    La fecha o etapa se muestra con texto, no solo con color.

  3. Etapa 3

    Tercer hito

    El último elemento cierra la secuencia sin agregar una línea extra.

Pasos

Para instrucciones breves y ordenadas.

  1. Escuchar sin juzgar

    La primera respuesta importa. No culpabilizar y no prometer secretos.

  2. Guardar pruebas

    Conservar mensajes, perfiles y fechas sin borrar la conversación.

  3. Pedir ayuda

    Contactar a un adulto de confianza o a una línea especializada.
